# Duplicate image report — public/images/brands/

Generated by a one-off scratchpad script (`find-dupe-images.js`). Nothing was deleted or modified.

## Method

- **Exact duplicates**: md5 hash of every file's raw bytes; any hash shared by 2+ files in the same brand folder.
- **Probable duplicates**: within a brand folder, files with the *same decoded (width, height)* whose file sizes are within **2%** of each other. Dimensions are read with the same PNG/JPEG/WebP header parsers used by `scripts/build-brand-media.js`.
- Files already listed as exact duplicates are excluded from the probable pass so nothing is reported twice.
- Probable matching is a **heuristic**: same pixel dimensions + near-identical byte count strongly suggests the same photo re-encoded, but it can also flag distinct photos exported with identical settings. Verify visually before deleting.
